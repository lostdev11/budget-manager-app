# Budget Manager App

A comprehensive budget management web application that helps you track your income, expenses, bills, subscriptions, and debt payoff strategies.

## Features

- Monthly income tracking
- Bill and subscription management
- Credit card tracking with APR calculations
- Debt payoff planning with multiple strategies
- Custom payoff plans
- Budget saving and loading
- Visual dashboard with charts
- Responsive design

## Setup

1. Clone the repository
2. Open `index.html` in your browser or use a local server:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser

## Development

The app is built using:
- React
- Tailwind CSS
- Chart.js
- Local Storage for data persistence

## Deployment

This app is deployed using GitHub Pages. To make changes:

1. Make your changes locally
2. Commit and push to GitHub
3. Changes will be automatically deployed
